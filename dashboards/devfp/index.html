看板口径与局限

只看用本机 DoT/DoH 的设备（服务器侧按指纹聚类）。数据来源三路：被动抓包（853/444/443 的 TLS ClientHello → JA3/JA4、TCP SYN → p0f 式指纹、握手 RTT）、AdGuardHome 查询日志（协议/查询行为）、nginx DoH 访问日志（HTTP 层指纹）。全部只读采集，不介入 DNS 解析链路。

设备卡片上的「推断」是用 TLS 栈结构 + TCP/IP 特征 + 查询域名 + HTTP 层 + 连接行为合成的结论，点开可看逐条证据。跨 NAT 看不到 MAC，因此无法对应到具体硬件型号；域名规则给出的厂商/OS 只是概率性线索，一律标注置信度并保留原始证据。证据不足就写「未识别」，不猜。

设备

设备按「JA4/JA3 + TCP + HTTP/DNS 行为」多证据聚类；单一 JA3/JA4 只作为线索，并显示置信度与漂移状态。点任意一行查看完整指纹与行为。名称可自行命名，命名后会同步到相同指纹的其他条目。

—

DoT 客户端（:853）

经 TLS 直连 853 的客户端。853 现由 Nginx stream 前置终结 TLS（明文 DNS 记录后转发给 AGH），因此除了 ClientHello/TCP 指纹，还能看到明文查询名、qtype、EDNS 特征（PADDING/DO 位/UDP 缓冲/COOKIE/ECS）、0x20 大小写随机化与每查询时延。

—

DoH 客户端（:443 与 :444 均经 nginx）

443 与 444 都由 nginx 终结 TLS 并反代到 AGH，因此两条路径都能拿到 HTTP 层指纹（UA、头集合、TLS 套件/曲线/ALPN/session 复用）与请求里解出的查询域名；AGH 侧记的是真实客户端 IP（XFF + trusted_proxies）。

—

指纹库

按 JA4/JA3 汇总本机观测到的 TLS 指纹，并结合 TCP、HTTP/DNS 行为判断置信度；单一指纹不直接等同于设备身份。可用来识别「换 IP 不换客户端」的同一台设备，或发现新的客户端软件。

采集说明与局限

      

        

          
DoT :853
由 Nginx stream 前置终结 TLS（AGH 的 853 已挪到宿主回环 127.0.0.1:8854），再以 DoT 转发给 AGH；devfp 仅旁路抓包观察。所以除 ClientHello/ServerHello 与 TCP 指纹外，还能拿到：逐连接的查询名/qtype/报文大小、EDNS 特征（PADDING 字节数、DO 位、宣称的 UDP 缓冲、DNS COOKIE、ECS）、0x20 大小写随机化、每查询时延。

          
DoH :443 / :444
两条路径都由 nginx 终结 TLS 并反代到 AGH（容器 443 只发布在回环 127.0.0.1:4443），可记录 HTTP 层（UA、头、方法、状态、URL/POST 里解出的查询域名、TLS 套件/曲线/ALPN/session 复用）。

          
查询行为的归属
AGH querylog 只按出口 IP 归属；DoT 明文用同 (ip, sport) 连接精确归属，命中不了时若该 IP 只有一台设备则按 IP 归属，否则不归属（宁缺勿错）。另有 AGH 日志与抓包记录毫秒级「时间对齐」作为兜底（仅独占 IP 有效）。

          
查询行为
由 AGH querylog 增量读取（协议、qtype、上游、过滤命中、时延、ECS、Top 域名、最近查询）。

          
设备聚类
JA4/JA3 + TCP 指纹；无 TLS 时退化为「源 IP + TCP 指纹」。

          
OS 猜测
启发式 p0f-lite（TTL 跳数/窗口/MSS/WScale/选项顺序），置信度分高中低，仅供参考，原始值一律完整保留。

          
探测连接
只完成 TCP 三次握手、不发 ClientHello 就关闭的连接（常见于上游健康检查/端口探测）会被标记为「无载荷探测」，并按其 TCP 指纹并入同源同指纹的设备，不会单独虚增设备。

          
握手时延
SYN-ACK 发出 → 客户端下一个包到达的实测 RTT（毫秒）。注意不是 SYN→SYN-ACK（那只是本机处理耗时）。

          
设备推断
跨 NAT 看不到 MAC；DoH 的 HTTP 层与 DoT 明文（Nginx stream）能看到一部分载荷，但都读不到硬件型号。推断引擎用七类证据合成厂商/OS/TLS 栈/版本区间/设备角色：①TLS 栈结构；②TCP/IP 特征；③查询域名规则库；④HTTP 层；⑤连接行为；⑥版本线索；⑦DoT 明文画像。每条证据都在设备详情「推断依据」里列出，证据不足就写「未识别」。

          
局限
① 服务器无公网 IPv6，只能看到 IPv4 客户端；② 家庭设备经 CPE NAT 后同源 IP，只能靠指纹区分，无法对应到具体硬件型号；③ DoH 只能看到请求元数据、DoT 明文只覆盖 DNS 层，都看不到「设备内哪个 App 在解析」；④ 域名规则给出的厂商/OS 是概率性线索；⑤ 服务器侧一律看不到 MAC，没有 OUI 厂商库可用；⑥ Nginx stream 终结后，AGH 面板里 DoT 的客户端维度会退化成前端一个 IP；⑦ devfp 重启前就建立、之后不再发 SYN/ClientHello 的长连接无法指纹化。

          
保留策略
连接明细保留 7 天、DoH 请求保留 14 天；最近查询环形缓存 4 万条；小时级聚合长期保留。
